# Bank Management System - Extension

An extended version of the Bank Management System developed using C++.

## 📌 Description

This project is an extension of the original Bank Management System.

The original project provides basic client management features such as adding, deleting, updating, finding, and displaying clients.

This extension adds a new Transaction Menu that allows users to perform financial operations such as deposits, withdrawals, and viewing the total balance.

## ✨ Features

### Client Management

- Display all clients
- Add new clients
- Delete clients
- Update client information
- Find clients by account number
- Prevent duplicate account numbers
- Store client data in a text file

### 💰 Transactions

- Deposit money into a client account
- Withdraw money from a client account
- Prevent withdrawals that exceed the account balance
- Display the total balance of all clients
- Display the updated account balance after transactions
- Confirm transactions before applying them

## 🗂️ Main Menu

The application provides the following options:

1. Print All Clients
2. Add New Client
3. Delete Client
4. Update Client Information
5. Find Client
6. Transaction Menu
7. Exit

## 💳 Transaction Menu

The Transaction Menu provides:

1. Deposit
2. Withdraw
3. Total Balance
4. Exit
